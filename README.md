# Accessible E-Learning Platform (Problem Statement 3)

A modern, futuristic metallic-themed e-learning platform designed to be fully accessible for students with visual, auditory, and cognitive disabilities.  
Built with WCAG 2.1 AA guidelines, multimodal learning support, and complete personalization controls.

## Features
- Metallic futuristic UI design  
- Text-to-speech & speech-to-text  
- High contrast mode & adjustable font size  
- Keyboard navigation  
- Screen reader support  
- Captioned videos + transcripts  
- User preference saving  
- Accessible course dashboard
